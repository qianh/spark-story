# 0001 外观登记与本集定妆

- 状态：已确认
- 日期：2026-09-08

## 上下文

定妆阶段能看到本集剧本和文字分镜，看不到已确认的完整故事稿。模型只能从本集事件猜测外观，镜头状态会写进定妆。

另一侧是：第一版目标是尽快做出第一集，不要求先写完、先画完全部集。

## 决策

全剧只登记外观，按集出图。

1. 完整故事稿是固定身份与形制的权威来源。确认后自动抽出外观登记，不出图，不加用户确认阶段。用户在定妆阶段审本集要出的图。
2. 文字分镜只引用实体和变体。视图写在机位/构图里，镜头状态写在本镜里，都不占定妆名额。
3. 定妆只生成「本集需要、库里还没有」的图。身份来自登记，不来自本集剧情。
4. 后续集复用已锁定定妆；新实体或变体才补登记并出图。

不采用「第一集前出完全剧定妆图」。

## 后果

- 第一集可以开拍，跨集脸和形制仍有全剧依据。
- 定妆阶段必须重新吃到完整故事稿 / 外观登记；不能再丢掉全剧上游。
- 后集才出场的角色，到那一集才有定妆图；关键帧不得引用未发布定妆。
- 同一地点默认一张主定妆。门外、末阶是视图，不新设计。完好山门与破败山门是变体，各出一张，仍属同一实体。
- 形制变了且后面还用：新定妆变体。只在这一镜发生的破坏：关键帧。
- 定妆重新生成是抽卡，不改已锁定规格。抽卡只追加候选，选中才发布。改 CONTENT / 画风 / 参考 / 变体才开新规格。审核文字不注入提示词。

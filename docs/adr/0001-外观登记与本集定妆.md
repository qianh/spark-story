# 0001 外观登记与全剧定妆

- 状态：已确认；2026-09-09 全剧共享资产表，按集增量出图
- 日期：2026-09-09

## 上下文

定妆用于给所有关键帧提供一致的角色、场景与道具参考，属于整部剧。此前将它定义为“本集需要、库里还没有”的资产调度，错误地将定妆归属于单集。

## 决策

1. 完整故事稿是固定身份与形制的权威来源。确认后自动抽出全剧外观登记，不出图，不增加用户确认阶段。
2. 定妆仍是全剧共享的一份资产表，所有集引用同一套已发布外观。出图按集增量：本批只强制当前集用到的实体与变体，已有资产保留；后集换装、破败、成长阶段等到那一集再补。不回到每集各做一份互不相认的定妆。
3. 文字分镜只引用实体和变体。视图写在机位与构图里，镜头状态写在本镜里。
4. 关键帧属于某一集的具体分镜，引用全剧已发布定妆，再叠加本镜内容，直接供分镜视频生成使用。
5. 画风为作品级单选；只有选择仙侠时才适用仙侠约束。切换画风后，定妆及下游画面按新画风重新生成，旧图不能作为新画风结果复用。

## 后果

- 完整故事确认后即可开始定妆，不必等某一集剧本或文字分镜。第一批只出第一集用到的外观，不阻塞在后段变体上。
- 切换集数显示同一份定妆任务。后集缺少变体时在同一任务上追加，不另建每集定妆。
- 同一地点默认一张主定妆。门外、末阶是视图；完好与破败属于可复用形制变体，各出一张。
- 只在某一镜发生的表情、动作、天气、破坏进入关键帧，不进入定妆。
- 定妆抽卡追加候选，选中才发布。改 CONTENT、画风、参考或变体开新规格；相关下游镜头须重新生成。审核文字不直接注入锁定生图提示词。

# 0003 国漫声音气质

- 状态：已确认
- 日期：2026-09-08

## 上下文

画面已锁三维仙侠国漫。声音若按真人影视或中年沉稳来写，会和年轻国漫听感不一致。沈不言一类角色性子可以冷，但不应被写成中年男主。

## 决策

增加作品级声音 DNA。填声音卡必须遵守；角色个性只写在卡里，不能把全剧改成中年腔。

年龄从全剧身份来，不从本集受伤、湿衣来。剧情明确年长才用中年/老年。重新生成试听是抽卡。

## 锁定全文

```
SERIES VOICE DNA — 主流国漫配音，全剧默认遵守：

听感参考国产仙侠/奇幻国漫配音：口齿清楚，有角色口吻，略带表演弹性，说话有来势。
默认年轻。非年长角色年龄段只许幼童、少年、青年，禁止中年、老年。
年轻角色用清亮、偏薄、有青春感的声线。青年/少年男性 pitch 只许 mid、mid-high 或 high，禁止 low 和 mid-low；语速不要 slow 或 slightly-slow。不要苍劲、沙哑沧桑、中年沉稳、中低音浑厚、过慢念稿、广播腔、纪录片旁白、欧美低沉暗黑。
不要死板平铺。活泼是「有口气、有配音感」，不是每个角色都卖萌或元气偶像。
剧情明确年长的角色才用中年/老年，仍保持国漫配音的清晰口吻，不要话剧老生。
声音卡只写听得见的声线，不写外貌、服饰、场景、本集天气。
```

## 后果

- 声音卡规划必须带上这段 DNA；编译出的 instruct 不得把非年长角色写成中年/老年，也不得出现「青年」：Qwen3-TTS 的年龄表里青年是 19 至 35 岁。
- VoiceDesign 才按自然语言设计声线。官方有效句式是「体现…声，音调…，营造出…听觉效果」，用具体岁数（幼童约 8 岁、少年约 15 岁、青年成长阶段写成 17 岁少年）。否定句和规格清单不是这个模型的主控制手段。
- CustomVoice 的 `--instruct` 只控制情绪/风格，年龄由预设音色决定。Aiden / Serena 不能靠提示词变成少年；幼童没有预设，走 VoiceDesign 或 `needs_voice`。
- 调用 VoiceDesign / CustomVoice 1.7B 时使用模型默认采样：temperature 0.9、top_p 1.0、repetition_penalty 1.05。不要沿用 mlx-audio CLI 的 0.7 / 0.9 / 1.1。
- 已有「克制、偏慢、中低音」卡若听起来老成，必须重填卡（青年改中音、语速中），不算同一规格抽卡。编译规则升级时，合格声音卡只重编译 instruct 并重抽音频，不重问文本模型。
- 声音跟成长阶段走，不跟换装走。每个成长阶段的人物主定妆默认一对一绑一张声音卡。换装不定新声。特殊剧情才允许同一张定妆另绑声音。
- 本集成效阶段：以本集镜头里该角色实际年龄为准。仅提及的往事不出图出声；闪回画面算出。同一集长大则两套并存。

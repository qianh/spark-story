# 0002 画风 DNA 与模块锁

- 状态：已确认
- 日期：2026-09-08

## 上下文

作品级只选一个画风：三维仙侠国漫。旧 STYLE LOCK 把「干净浅景、不要山不要楼」写进同一段，所以只能稳定出人物定妆。那是模块限制，不是能力限制。

若把整段 STYLE LOCK 贴到山门或佩剑上，会和 `no architecture` 打架。若执行时另写一套制作风格，发出去的字又不是用户选定的画风。

## 决策

把画风拆成短正向 DNA、共用片场语言、构图模块、CONTENT。公共 DNA 全系列不改，只写允许什么；人物 / 道具 / 场景共用 SAME SERIES STAGE，模块只换构图。生图只换模块和内容，DNA 原文不动。

真正统一靠一张过关的沈不言定妆作 Master Ref，不靠把锁写更长。其余正式资产绑定这张参考；换角色时风格高、脸低。无参考不得入库正式资产。

异类只改人设 CONTENT，不换渲染器。窥伺影的灰金肤、空眼眶、焦金骨漆袍是物种，不是锁错。

「人在景里的剧照」不是定妆：定妆场景默认没人。人进画面属于关键帧。场景词用 donghua background art / animation layout，不用 mountain photo。

## 锁定全文

### 公共画风 DNA

```
XIANXIA DONGHUA LOOK v5
Chinese 3D donghua / 仙侠国漫 asset from one same series.
Stylized 3D animation character and set, manhua beauty, smooth doll-smooth skin, graphic elegant eyes, clean ink-mineral colors.
Series palette: ink, dark teal-black, bone-white, muted jade, aged bronze.
Donghua film lighting: soft key, clean rim on edges, even readable volumes.
Same render family as a Chinese immortal-game character poster and donghua background art.
```

全文、SAME SERIES STAGE 与三套构图模块以 `packages/visual-style.ts` 的 v5 锁定为准。短正向锁；禁止句改用正面替代（写 smooth doll-smooth skin，不写 no pores / NOT photoreal / Unreal / documentary）。正式资产必须绑定沈不言主参考。

### 人物模块

人物模块与 CONTENT — CHARACTER 模板以 `packages/visual-style.ts` 锁定全文为准。人物定妆仍是灰棚全身站立，不进山、不进楼。

### 道具模块

道具模块与 CONTENT — PROP 模板以 `packages/visual-style.ts` 锁定全文为准。道具是同一部仙侠片的虚构法器，不是博物馆文物照。

### 场景模块

场景模块与 CONTENT — SCENE 模板以 `packages/visual-style.ts` 锁定全文为准。场景是构造出来的宗门片场，不是现成景区。同一地点非变体只出一张主定妆；门外、末阶是视图，不另出图。人要进景时不换人物模块，只在场景 CONTENT 末行加远处人。

内容禁用：photoreal、live-action、pores、photorealistic landscape、real temple、tourist、ordinary、simple、worn everyday、museum antique、DSLR、National Geographic、Huangshan、readable sign、epic magic、lightning、anime、illustration。

## 后果

- 人、剑、山门都是同一部剧：同一 DNA、同一片场语言，构图不会互抢。
- 作品保存的画风必须同时存 DNA 和三套模块，不能只存旧 STYLE LOCK 一段。
- 规划只填对应 CONTENT，禁止再写画风句；执行器原样拼接，不得改 DNA 或模块。
- 正式资产必须绑定沈不言主参考。无参考连抽不算入库。
- 旧 STYLE LOCK 全文不再作为场景/道具提示词。当前配置是 `xianxia-style-dna-v5`，停用 v4 负向锁。

# Spark Story：个人动漫短剧制作工作台

版本：0.1；日期：2026-09-05；状态：基于已确认访谈整理的产品设计，尚未实现。

本文中的产品规则来自已确认需求；标为“建议默认值”的细节是实施建议，可通过配置调整。技术方案见 [02-技术设计.md](02-技术设计.md)，开发与验收见 [03-实施与验收.md](03-实施与验收.md)。

## 1. 产品目标与第一版边界

用户在本机浏览器里管理一部动漫短剧，主控 Agent 协调专业子 Agent，从原始创意或文本推进到可播放、可修改、可导出的成片。用户掌握关键节点的创作决定，也能随时进入任意 Agent 工作区进行干预。

第一版验收目标是完整制作第一集。集数、时长由故事和改编决定，不设置固定集数、每集时长、每集镜头数。数据结构从第一天支持多集、共享角色和跨集连续性，但不要求在制作第一集前写完所有集。

第一版包含全部已确认制作环节、多模型与 CLI 接入、真实任务运行、产物审核、重做、断点恢复和导出。暂不建设多用户协作、对外计费、完整专业多轨剪辑器或自动发布到视频平台。

## 2. 已确认的产品规则

| 领域 | 规则 |
| --- | --- |
| 部署 | 本机后台常驻，浏览器操作；关网页不停止制作 |
| 内容入口 | 一句话创意、粗略剧情、完整小说或剧本 |
| 改编 | 默认适度改编；重大改变在审核材料里明确呈现 |
| 规划 | 先全篇概要与人物设定，再细化第一集 |
| 执行 | 主控 + 预设专业子 Agent，同类 Agent 可并行启动 |
| 模型配置 | 主模型、文本、图片、视频、语音、其他六类 |
| 接入 | 主流供应商 API Key；Codex CLI、Claude Code CLI、Grok Build、grokcli |
| 审核 | 子任务先过主控；关键阶段集中交给用户 |
| 返工 | 默认最多自动返工 3 轮，可配置；执行异常单独处理 |
| 干预 | 子 Agent 立即停自己并汇报主控；主控决定其他任务停不停 |
| 恢复执行 | 明确修改要求直接执行；模糊不满意先形成方案等确认 |
| 费用 | API 调用受预算控制；CLI 调用不套用平台金额上限 |
| 视觉 | 多套可选模板，可编辑并添加参考图 |
| 画幅 | 项目级 9:16、16:9、自定义比例 |
| 声音 | 系统推荐并生成试听，用户确认后绑定角色 |
| 音画路线 | 主控按镜头与模型能力选择，用户可覆盖 |
| 后期 | 自动成片；支持局部编辑；音乐音效优先 AI，也支持本地素材 |
| 版本 | 保存全部产物版本；明确指定正式版本；新候选不自动覆盖 |

## 3. 项目创建与故事理解

### 3.1 创建项目

必填项尽量少：项目名、内容入口、原始内容。画风、画幅和模型配置可选择已有模板。预算仅用于 API，未配置 API 时不强迫填写。

建议默认中文对白和字幕。语言、分辨率、帧率、字幕样式属于项目设置，不写死在 Agent 提示词里。自定义比例必须为正数；实际输出尺寸由选定模型能力决定。模型不支持该比例时，在生成前给出适配方案，不能默默裁掉主体。

模型尚未配置完整也能创建项目、整理剧本；进入需要该能力的阶段才提示配置缺项。

### 3.2 三种入口的处理

| 入口 | 系统工作 | 应避免的问题 |
| --- | --- | --- |
| 一句话创意 | 扩展故事主线、冲突、人物关系、世界规则、阶段性走向 | 把未经确认的新增设定当成用户原意 |
| 粗略剧情 | 补足因果、动机、过渡、结局方向和可视化表达 | 补全时不保留原始内容 |
| 小说或剧本 | 分章分场解析、归纳全篇、建立人物别名与事实索引、提出改编策略 | 只读开头就声称已理解全篇 |

建议首批导入格式为粘贴文本、TXT、Markdown、DOCX、文字型 PDF；扫描件通过 OCR 能力导入，低置信度段落提示复核。原始文件不可变保存，解析结果记录章节、段落或页码来源。

长篇输入采用分段提取和分层汇总，保留处理覆盖率、未解析范围、人物事实及其出处。全篇尚未完成梳理时，不能提交“全篇已梳理”的审核包。概要可以逐步完善，原作事实与改编建议分开记录。

### 3.3 故事资料库

维护故事主线、人物关系、世界规则、时间线、地点、伏笔及回收点、已发生事件、未揭示信息。人物的“客观身份”和“本集观众已知信息”分开，避免第一集提前泄露后续秘密。

用户确认故事概要时，可以确认大方向并保留未定项。未定项若会阻碍第一集制作，主控先提出方案；不阻碍的内容不强制补齐。

## 4. 制作阶段与审核关卡

| 阶段 | 主要输入 | 主要产物 | 用户确认内容 |
| --- | --- | --- | --- |
| 故事概要 | 原始内容 | 故事概要、人物关系、世界规则、改编说明 | 故事方向和改编边界 |
| 第一集剧本 | 已确认故事资料 | 分场剧本、动作、对白、旁白、结尾衔接 | 本集内容、台词和节奏意图 |
| 定妆与资产 | 剧本、画风模板 | 角色设定图、服装、表情、场景、道具、声音试听 | 角色外观、声音、主要场景与整体风格 |
| 分镜与动态预览 | 剧本、正式资产 | 分镜表、预览图、临时配音、动态分镜 | 镜头表达、构图、对白与节奏 |
| 正式镜头制作 | 已确认分镜 | 正式关键帧、配音、镜头视频、口型处理结果 | 阶段结果可随时查看；集中进入成片审核 |
| 后期与成片 | 主控通过的正式素材 | 剪辑、音乐音效、混音、字幕、成片 | 最终视听效果和导出版本 |

以上为业务阶段，不是不可变的串行脚本。例如文字分镜草案和角色设计可以在剧本通过后并行；动态分镜提交前必须引用正确资产。通过预览审核后，多个镜头可以并行生成。

阶段卡片不直接等同某个 Agent。一阶段可以包含多个专业 Agent，一个 Agent 类型可以参与多个阶段。

### 4.1 剧本内容结构

每场包括地点、时间、出场人物、场景目标、冲突、情绪变化、动作、对白、旁白及与前后场的关系。台词具有稳定 ID，分镜引用该 ID，而不是反复复制文字。

剧情 Agent 对适度改编生成简明变更表：原作片段、改编内容、原因、影响。重大变动提交给用户审阅；用户明确提出的改动直接作为授权。

### 4.2 视觉模板与角色资产

建议首批内置模板：清新日系、热血赛璐璐、国风水墨、国风精细动画、Q 版轻喜剧、柔和三维动画。这些是自有风格描述模板，不承诺任意模型都能严格复现。

模板包含视觉描述、线条、色板、材质、光照、角色比例、背景复杂度、构图倾向、负向约束与参考图。项目创建时复制模板版本；后续修改公共模板不自动改变已有项目。

角色资产根据拍摄需求生成正面、侧面、背面、面部近景、常用表情和服装状态。原始设定图与模型需要的单张参考图分别保存，避免把整张多视图设定表直接用于单镜头生成而产生多人。

场景包含空间关系、关键区域的标准外观；时间与天气由关键帧按剧情生成，不做成资产变体。道具包含尺寸关系与标准外观；持有方式和临时剧情状态由关键帧表达。角色换装、受伤、年龄或能力外貌变化才新建定妆版本，不随每次生成随意变化。

### 4.3 分镜与动态预览

分镜字段包括：场景、镜头顺序、景别、机位、运镜、人物及站位、动作、对白引用、画外音、情绪、估计时长、转场、资产版本、关键帧需求、口型需求、音画路线。

动态分镜使用预览图或可复用关键帧、临时音轨和预计时长合成。清晰标记临时素材；正式视频任务必须等待该阶段通过。预览图满足正式要求时可复用，不为了流程形式强制重生成。

### 4.4 音画路线

| 路线 | 使用条件 | 执行与检查 |
| --- | --- | --- |
| 独立配音驱动 | 明确对白、角色声音稳定性要求高、工具支持驱动或口型处理 | 生成配音 → 按实际节奏组织镜头 → 生成/同步口型 |
| 原生音画生成 | 视频模型支持所需语言、台词与声音控制 | 生成音画 → 核对台词、音色、口型与视频 |
| 分别生成后合成 | 旁白、画外音、动作与空镜，或已有视频素材 | 独立生成画面和音轨 → 时间线合成；出镜说话时补口型处理 |

原生音画路线不能取消已确认的角色声音约束。模型无法满足时，主控选择独立配音路线或提出变更，不默默换声。

一句台词可以跨多个镜头，一个镜头也可包含多人轮流对白。逻辑镜头长于供应商上限时拆成生成片段；成片保留逻辑镜头与片段的对应关系。

## 5. 主控与专业 Agent

| Agent | 主要职责 | 交付物 |
| --- | --- | --- |
| 主控 | 分析、规划、派发、检查、阶段提交、干预协调 | 任务图、审核结论、变更影响、用户待办 |
| 剧情 | 概要、改编、人物关系、分集建议、本集剧本 | 结构化故事与剧本 |
| 分镜 | 剧本可视化、镜头衔接、节奏、音画路线建议 | 分镜计划与动态预览计划 |
| 角色与资产 | 定妆、表情、服装、场景、道具 | 带语义和版本的资产包 |
| 关键帧 | 依据正式资产生成具体镜头画面 | 首帧、尾帧或其他必要关键帧 |
| 视频 | 镜头生成、延长、口型工具调用、片段整理 | 视频片段与执行记录 |
| 配音 | 声音推荐、试听、台词、情绪、语速、时间对齐 | 角色声音绑定与对白音轨 |
| 音乐音效 | 配乐、氛围、动作音效和放置计划 | 可分离音乐、音效、氛围轨 |
| 后期 | 动态预览、成片剪辑、混音、字幕、导出 | 时间线版本、字幕和成片 |

专业 Agent 可以使用多个能力。例如角色与资产 Agent 用文本能力整理提示词，再调用图片能力。用户仍只需要理解六类模型配置。

## 6. 审核、返工与人为干预

### 6.1 主控审核

主控审核实际产物和检查报告，不接受“子 Agent 自述完成”作为唯一证据。

文本检查结构、人物动机、因果、设定一致性和来源；图片检查人物、服装、数量、构图和关键缺陷；视频检查文件可解码性、时长、抽帧内容、衔接和音轨；音频检查台词转写、遗漏、重复、静音、削波与可听性。

自动检查覆盖范围有限：视频抽帧不能证明每一帧无异常，语音转写也不等于口型一致。报告标记检查方法、证据时间点和不确定项，最终创作判断由用户完成。

默认“3 轮返工”解释为首次生成后，最多额外返工 3 次。主控每次必须给出具体问题与修复要求。达到上限后保留最佳候选、全部意见与失败原因，暂停该任务。

用户提交新的明确要求会创建新修订周期，重新计算该周期的质量返工次数；过往费用和记录继续保留。超时、限流、鉴权失败不计入质量返工轮次。

### 6.2 审核界面

审核包展示当前版本、上次版本差异、主控结论、问题定位和下游影响。支持通过、明确修改、模糊否定、直接编辑、替换文件。批量通过只作用于明确展示的版本集合。

用户可以明确接受主控提示的审美或质量问题；文件损坏、缺少必要输入等不可执行问题不能伪装为可继续生成。

### 6.3 实时干预

用户点击中断或在子 Agent 工作区发送修改意见，即停止该子 Agent 新动作，并持久记录中断汇报。不能依赖模型先生成一段汇报文字才停下来。

主控收到汇报后判断任务依赖和语义影响，决定暂停其他哪些任务。子 Agent 不拥有停止其他 Agent 的权限。主控暂不可用时，已受中断影响的旧结果不会自动流入下游，界面显示等待协调。

明确要求：主控直接落实，不因涉及已确认内容重复请求授权；只对执行所需但缺失的关键选择进行询问。模糊否定：形成建议方案及影响范围，等待用户确认。超出 API 预算仍按预算规则暂停。

外部任务不能取消时，显示“本地已中断，供应商仍在执行”；返回旧结果保存为旧修订候选，不能覆盖最新内容。

## 7. 页面结构

### 7.1 全局导航

项目列表、模板库、模型与连接、Agent 配置、运行与恢复中心、设置。进入项目后显示阶段看板、资产库、镜头列表、成片、历史记录与主控聊天入口。

### 7.2 项目阶段看板

```text
项目名 / 当前集     画幅     API 已用/预留/上限     CLI 状态
故事概要 | 本集剧本 | 定妆资产 | 分镜预览 | 正式镜头 | 后期成片

当前阶段：正式镜头              待处理：1 个任务需要你的意见
任务卡：镜头 01 / 视频 Agent / 外部生成中 / 打开工作区
任务卡：镜头 02 / 配音 Agent / 主控审核通过 / 试听
任务卡：镜头 03 / 视频 Agent / 返工第 2 轮 / 对比版本

右侧可展开：主控聊天 / 当前计划 / 最近决策
```

阶段进度以任务完成数量、审核数量、阻塞数量表达。供应商没有真实百分比时只显示已提交、排队、生成中与等待时长，不编造进度。

### 7.3 子 Agent 工作区

顶部显示任务、角色、模型连接、运行状态、修订、已用费用或 CLI 状态，以及立即中断按钮。

左侧为输入资料和约束；中间为产物预览与版本对比；右侧为执行事件、主控审核意见和用户干预。图片支持缩放与并排对比；视频支持播放、逐帧/时间点问题定位；音频支持波形、台词和试听；文本支持差异编辑。

展示可用的执行事件、工具调用摘要和决策说明，不把模型内部推理作为产品依赖。命令详情折叠显示并去除密钥。

### 7.4 资产库

按角色、服装、场景、道具、声音、分镜图、视频、音乐、音效分类；支持搜索、标签、来源、正式版本、候选版本和引用关系。点击角色资产可看到哪些镜头引用它。

### 7.5 成片与局部编辑

左侧镜头列表，中间播放器，下方简化时间轴，右侧选中项参数。支持排序、裁切、过渡、镜头替换、分轨音量、背景音乐、字幕样式和文本校正。

调整镜头顺序或音量只重新合成；修改台词则重做配音、字幕对齐及相关口型；修改角色外观则重做引用该外观的图片/视频。不要把每次编辑都变成整集重生成。

### 7.6 模型与连接

六类能力各设置默认连接、模型、参数和已授权备用顺序。项目可覆盖全局配置，任务可覆盖项目配置。展示连接健康度、能力缺项、CLI 版本和模型可用性。

API 配置包含供应商、地址、密钥引用、模型、费用配置和并发；CLI 配置包含工具种类、绝对可执行路径、版本、模型、登录状态和并发。不把 CLI 不受金额限制显示为“免费”。

## 8. 预算与运行状态

API 预算展示已结算、已预留、费用未知及剩余额度。提交前预留，完成后结算；并行任务共享额度。无法准确估价时使用配置的保守预估，完全无法估计则先提示配置费用上限或未知费用策略。

CLI 不按平台预算中断，也不因为累计 token 达到平台自定上限停机。CLI 自身限流时按工具提示等待恢复；额度耗尽、登录失效或不可恢复错误时暂停对应连接。正常终止、任务完成和质量返工上限仍然有效。

CLI Agent 调用平台付费图片/视频/语音 API 时，这些 API 调用仍要预留和结算。备用连接从 CLI 切到 API 时同样检查预算。

## 9. 导出与完成定义

建议默认导出 MP4 成片、SRT/ASS 字幕、独立对白/音乐/音效轨、项目时间线 JSON 与产物清单。用户可选择烧录字幕或独立字幕；导出记录画幅、分辨率、帧率、素材版本和时间线版本。

第一集完成意味着：关键节点已确认，正式素材通过主控检查，成片通过用户审核，可播放且可导出；过程可追踪、可恢复、可局部修改。仅有页面、模拟进度或拼接演示素材不算完成。
